# clang

C and C++ from Arch: the clang compiler with clangd, clang-format and clang-tidy, the lldb debugger, the mold linker, and meson.

They come from pacman, not mise. They build and link against this system's glibc and headers and update with `pacman -Syu`, and mise's only clang is a conda build. meson is a Python program, and Arch rebuilds it when the system Python moves. A copy in a uv environment would break then. `gcc` and `make` come with `base-devel`, and `cc` stays gcc. cmake and ninja come from [mise](mise.md).

To link with mold, pass `-fuse-ld=mold` to clang or gcc, or `-C link-arg=-fuse-ld=mold` to rustc. helix debugs C, C++, Rust and Zig through `lldb-dap`.
