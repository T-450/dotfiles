# ghostty

The terminal (alt+return), the dropdown terminal (alt+esc) and the floating terminal (alt+shift+t), also every app's terminal: `xdg-terminals.list` names it for xdg-terminal-exec, which GLib uses to start `Terminal=true` apps (helix, vim).

Every window is its own process (`gtk-single-instance = false`), as kitty's were. Ghostty's single instance opens each new window in `~` instead of the directory it was launched from (Thunar's "Open Terminal Here"), and gives all windows one pid, so mango's swallowing could hide the wrong terminal. A window takes about 0.3 s to open and 75 MB.

The dropdown is a Ghostty window with the app id `com.mitchellh.ghostty-dropdown` (`--class=`), shown and hidden by mango's `toggle_named_scratchpad` (`mango/.config/mango/bind.conf`, rule in `rule.conf`). The first alt+esc starts it; after that alt+esc shows or hides the same shell, so history and running jobs survive. It floats against the top edge of whatever tag you view, 80% of the screen wide and half as tall, and alt+q closes it like any window. Ghostty's own quick terminal is not used: it is a layer surface, which mango never selects, so alt+q while it was open would close whichever window mango had selected instead.

The floating terminal is a new Ghostty with the app id `com.mitchellh.ghostty-float` each time: `rule.conf` floats it at 800x600 in the middle of the screen. Use it for a one-off command next to a tiled layout; the dropdown is the shell that persists.

Copy and paste work like in GUI apps:

- **Ctrl+C** copies the selection and clears it; with nothing selected it is ^C (interrupt) as always, so the next Ctrl+C after a copy interrupts again (a `performable:` bind with `selection-clear-on-copy`).
- **Ctrl+V** pastes the clipboard (bracketed paste: the shell inserts it without running it). Ctrl+Shift+C/V still work.
- A literal ^V (vim's block select, zsh's quoted-insert) is **Ctrl+Shift+Alt+V**.
- Selecting text fills the primary selection, so middle click pastes it anywhere.
- **Ctrl+click** opens a link (Ghostty underlines it while Ctrl is held).

Text looks exactly as it did in kitty: `alpha-blending = linear` draws the same glyphs (Ghostty's default draws them lighter), and `adjust-cell-height = 1` makes the cells 10x22 px (Ghostty's own line height for JetBrains Mono at 12 pt is 21 px). fastfetch's logo is sized for those cells. Window padding is 1 px narrower on the left: Ghostty takes whole points only.

Colors come from `colors.ghostty` (the palette's terminal colors, the split divider and the search highlights) and `tabs.css` (the tab bar). `theme set` recolors open windows at once: `reload.sh` sends SIGUSR2, which makes Ghostty re-read its config, `tabs.css` included. Tabs (ctrl+shift+t) show at the top only when there are two or more: `tabs.css` turns libadwaita's rounded tab bar into square segments one cell tall in the terminal's font, the selected one in the accent, like the bar. Splits are Ghostty's defaults (ctrl+shift+o right, ctrl+shift+e down); an unfocused split is dimmed. fastfetch draws its logo through the kitty graphics protocol.

Not carried over from kitty: the cursor trail (Ghostty draws one only with a custom shader, whose animation loop renders every frame while the window has focus, a steady cost on a laptop), the blinking that stops after 15 s, curly link and undercurl styles, and the powerline slants and tab numbers.
