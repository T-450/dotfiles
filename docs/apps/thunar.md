# thunar

Thunar, the file manager (super+f), with thumbnails, archives, network places and automounting.

Super+F opens it, as a 720x480 floating window like the other GTK apps (mango's `rule.conf`). `thunar.service` runs it as a daemon from the start of the session, so windows open at once, "show in folder" from other apps reaches it (it owns `org.freedesktop.FileManager1`), and thunar-volman can mount removable drives and media as they are plugged in (it works only while Thunar runs).

The plugins and helpers come from `packages`: archives through the context menu (thunar-archive-plugin with xarchiver, the only archiver, so it never asks which one), media tags, tumbler thumbnails for video, PDF, office, e-book, RAW and HEIF files, and gvfs for the trash, phones (MTP, gphoto2, AFC) and network shares (SMB, NFS). "Open Terminal Here" opens Ghostty in that folder (`~/.config/xfce4/helpers.rc`).

`setup.sh` makes Thunar the default for folders and xarchiver the default for every archive type it handles, and sets Thunar's preferences in xfconf (which saves by renaming its file, so the repo can't link it): delete in the context menu, middle click opens a tab, ISO dates, item counts and thumbnails only for local files, and automount for drives and media. Without a session bus (a bare VM) it sets the defaults and skips xfconf.

**Packages** (`thunar/packages`): `thunar`, `thunar-archive-plugin` (extract/compress from the context menu (backend: xarchiver)), `thunar-media-tags-plugin`, `thunar-volman` (automount removable media while Thunar runs), `tumbler` (thumbnails, with the loaders below), `ffmpegthumbnailer`, `poppler-glib`, `libgsf`, `libgepub`, `libopenraw`, `libheif`, `gvfs` (trash, network locations), `gvfs-mtp`, `gvfs-gphoto2`, `gvfs-afc`, `gvfs-smb`, `gvfs-nfs`, `udisks2`, `xarchiver` (the only archiver, so the archive plugin never asks which one), `7zip`, `unrar`

**Linked into your home** (stow, `install.sh --link`):

- `~/.config/systemd/user/thunar.service`
- `~/.config/xfce4/helpers.rc`

**User units** (enabled by `install.sh --units`): `thunar.service`

**`setup.sh`** (run by `install.sh --setup`): Thunar's settings (xfconf, which saves by rename, so not a linked file), automount, and Thunar/xarchiver as the default folder and archive apps. xfconf needs a dbus session; skipped without one.

**`reload.sh`** (run by `theme set`): restart the Thunar daemon so its windows get the new colors. GTK reads gtk.css once per process and every Thunar window belongs to the daemon, so only a restart recolors it. A restart closes Thunar's windows and stops their copies: with one open, or when mango can't say, the hook leaves the daemon alone and says so.
