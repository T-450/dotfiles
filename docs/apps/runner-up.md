# runner-up

CI on this machine: [runner-up](https://github.com/kunchenguid/runner-up) runs this repo's GitHub Actions jobs, each in a fresh Arch Linux KVM VM.

The coordinator (`runner-up.service`, running while logged out thanks to linger) uses `gh`'s sign-in and serves `T-450/dotfiles` on pool `arch-kvm`: one place of 4 cores / 6 GB, keeping 4 cores / 8 GB for you. `setup.sh` installs the pinned release and the Arch cloud image, both checked against pinned SHA-256s; bump them with `config.json`. `runner-up status` shows the place. See [Testing and CI](../testing.md).
