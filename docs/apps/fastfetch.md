# fastfetch

System summary beside Godzilla breathing fire into a starry sky, drawn by Ghostty through the kitty graphics protocol.

`render.sh` (run by `theme`) makes `logo.png` from the illustration (`pkg/godzilla-starry-sky-art`: its license is unknown, so it is downloaded and checked by SHA-256, never committed). It crops to the breath, the head and the claws and keeps the art's own deep blues, which sit in a dark terminal. A slightly widened Lanczos filter keeps the fine linework from aliasing into noise, and the image is scaled to exactly the logo's 26x17 cells at Ghostty's 10x22 px cells (font-size 12), so Ghostty draws it 1:1 with rounded corners. Change the font size or the cell height (`adjust-cell-height`) and the logo needs new numbers in both `render.sh` and `config.jsonc.tmpl`. The logo type is `kitty-direct`: Ghostty reads the PNG and fits it to that cell box. Plain `kitty` makes fastfetch resize the image first, from the window's pixel size per cell, which Ghostty reports with the window's leftover padding included (22.3 px rows instead of 22), so the logo came out soft. The logo spans the title down to the color dots, with a blank row above and below.

The summary uses the palette: your user name in the accent, system keys in the accent and hardware keys in the palette's gold (`warning`), usage bars in its success, warning and error colors. Memory, disk and battery show one bar plus their numbers, so even a quarter-screen terminal (79 columns) fits every line; a narrower one clips lines (`disableLinewrap`) instead of wrapping them under the logo. Only `config.jsonc` and `logo.png` are linked, so other presets in `~/.config/fastfetch/` stay yours.
