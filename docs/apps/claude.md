# claude

Claude Code: its settings and a custom theme rendered from the palette. Also the Claude desktop app (`claude-desktop`, AUR), installed as is: it keeps its own settings.

`~/.claude/settings.json` (theme `custom:mango`, model and effort, plugins, marketplaces, push notifications, auto mode rules) and `~/.claude/themes/mango.json` are linked from the repo like any config. Auto mode asks before removing a package or stopping, disabling or reenabling a unit: `systemctl --user disable` on a linked unit deletes the repo file. `claude auto-mode config` prints the rules in effect. `~/.claude/CLAUDE.md` holds the instructions every agent session gets in any project (tone, commit rules, quality bar); Pi reads the same file as `~/.pi/agent/APPEND_SYSTEM.md`, a link in `pi/` to this one. Project rules stay in each project's AGENTS.md. Change settings by editing the repo file; if Claude Code ever replaces the link with a real file, `install.sh --check` reports it and the next `install.sh` backs it up and restores the link.

Context and cost: the Bash tool runs bash (`CLAUDE_CODE_SHELL`), because zsh's `nomatch` failed agent commands with unquoted globs such as `--include=*.rs`; the PATH still comes from the zsh that started Claude Code. A `SessionStart` hook adds `mise hook-env` to `$CLAUDE_ENV_FILE`, which Claude Code sources before every Bash command, so a project's mise tools and env follow the agent's `cd` the way they follow a terminal's ([mise: Claude Code](https://mise.jdx.dev/agents.html#claude-code)). It sets `MISE_VERBOSE=0` there, so mise's debug lines never reach tool output. `setup.sh` registers mise's MCP server (`mise mcp`) at user scope in `~/.claude.json`, which Claude Code owns, so it can't be a linked file; `mcpServers` in `settings.json` is ignored. The server has no `--cd`: it starts in the session's directory and describes that project's tools, tasks, env and config. Its env resource carries real values, secrets included, and `run_task` and `install_tool` act only in a trusted project. Subagents default to Sonnet (`CLAUDE_CODE_SUBAGENT_MODEL`); a call that names a model (Fable for design review, Opus for a final review) overrides it. Opus auto-compacts at 400k tokens (`autoCompactWindow`) instead of near 1M, since every call re-reads the whole context. Plugins synced from claude.ai that are never used here are off (`"<name>@synced": false`), and so is `research-superpowers`, which adds a skill index and a drift check to every session start; set one back to `true` in a project's `.claude/settings.json` to use it there. Auto mode also treats the desktop-vm loop and scratchpad preview renders as routine.
