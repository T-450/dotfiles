# base

The system layer: kernel, bootloader, networking, sudo and the tools install.sh itself needs.

archinstall installs most of it; it is declared so a clean install and `tools/docs --drift` agree. NetworkManager uses iwd for Wi-Fi; zram swap compresses with zstd (both files in `base/root/etc/`).

The firewall is on: `base/root/etc/ufw/ufw.conf` sets `ENABLED=yes` (Arch ships `no`, which leaves `ufw.service` running with no rules) and Arch's own `/etc/default/ufw` drops incoming and allows outgoing traffic. Nothing listens for the network by default, so nothing is opened; a port a container publishes is filtered like any other (publish to `127.0.0.1` unless another machine needs it). Open one with `sudo ufw allow <port>/tcp`; check with `sudo ufw status verbose`. In CI the guest's firewall comes on mid-job, which is safe: runner-up drives the job over one SSH session opened before it, and ufw keeps established connections.
