# chrome

Google Chrome stable, tuned for speed on this T14 and with ads blocked by uBlock Origin Lite. It is the default browser (super+b, web links and HTML files: `chrome/setup.sh`).

- **Flags** (`~/.config/chrome-flags.conf`, read by the AUR launcher): native Wayland
  (`--ozone-platform-hint=auto`) and VA-API video decode/encode on the Intel GPU
  (`AcceleratedVideoDecodeLinuxGL,AcceleratedVideoEncoder`, the Chrome 143+ names from the Arch wiki).
  Check at `chrome://gpu` (Video Decode: Hardware accelerated).
  No touchpad gestures, as in mango: `--disable-features=TouchpadOverscrollHistoryNavigation` (a
  two-finger sideways swipe scrolls instead of going back or forward) and `--disable-pinch` (a pinch
  does not zoom; ctrl+-/= do). Check at `chrome://version` (Command Line).
- **Policies** (`/etc/opt/chrome/policies/managed/dotfiles.json`, every profile, shown at
  `chrome://policy`):
  - `ExtensionInstallForcelist`: uBlock Origin Lite (`ddkjiahejlhfcafbddmgiahcphecmpfh`). Chrome no
    longer runs Manifest V2 extensions, so classic uBlock Origin is not an option.
  - `HighEfficiencyModeEnabled` + `MemorySaverModeSavings: 1`: Memory Saver on, balanced; inactive
    tabs are discarded to free RAM.
  - `TabDiscardingExceptions`: `notebook.google.com` (Gemini Notebook, formerly NotebookLM), so Memory Saver never reloads a notebook tab
    with a chat in progress.
  - `BackgroundModeEnabled: false`: no Chrome process left running after the last window closes.

Managed policies apply to every Chrome profile, including ones automation starts; the flags apply only
to Chrome started through the launcher.
