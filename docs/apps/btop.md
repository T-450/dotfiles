# btop

btop, the system monitor (CPU, memory, disks, network, processes), in the palette's colors.

`theme` renders `mango.theme` from `mango.theme.tmpl` and links it into `~/.config/btop/themes/`. `setup.sh` points btop at it (`color_theme = "mango"` in `~/.config/btop/btop.conf`). btop owns that file and rewrites it whole when an option changes in its menu or its version moves, so the repo doesn't link it: every other option stays yours. `theme set` sends open btops SIGUSR2, which makes them re-read the config and the new colors.

Boxes are `fg_muted`, since the border roles sit at 1-2:1 on `term_bg`. Load and temperature run from `success` through `warning` to `error`; memory uses `info` (free), `link` (cached) and `success` (available); every foreground passes `|legible:term_bg`, so light palettes stay readable.
