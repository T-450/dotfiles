# walker

The launcher (`super+d`), clipboard history (`super+v`) and dmenu picker (`theme pick`, `nightlight menu`), powered by Walker (GTK4) and Elephant's minimal provider set (`desktopapplications`, `runner`, `clipboard`, `menus`).

Both `elephant.service` and `walker.service` (`walker --gapplication-service`) run as user units for instant launch. The `viewport` theme mirrors the bars: a centered 600px 0px opaque `vp_bar` dialog with a 1px `vp_cyan` 45% frame, an 8px/32px cyan ruler under the search entry, Terminess pixel type, and a 2px `vp_signal` left rail + 14% `vp_cyan` fill + 1px `vp_cyan` bottom rule on the selected row.
