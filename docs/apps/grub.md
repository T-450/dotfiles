# grub

The boot menu: GRUB with a ThinkPad-style theme, dark, at full-HD scale.

The theme is [AlexanderKh/lenovo-thinkpad-efi-grub-theme](https://github.com/AlexanderKh/lenovo-thinkpad-efi-grub-theme),
modeled on the firmware menus of new ThinkPads. `pkg/grub-theme-lenovo-thinkpad-efi` builds it
from a pinned commit with the project's own `build.sh 1.5 d` (scale 1.5 for 1920x1080, dark).
build.sh draws its PNGs with svgexport, an npm tool that runs headless Chrome; the PKGBUILD hands
that job to `rsvg-convert`. The Lenovo and ThinkPad logos are Lenovo's, so they come with the
download and never into this repo. The package installs the theme to
`/boot/grub/themes/lenovo-thinkpad-efi-dark/`, on the ESP beside `grub.cfg`, so GRUB reads it from
the partition it boots from rather than from the f2fs root.

`root/etc/default/grub` replaces grub's own file: this machine's settings plus `GRUB_THEME`,
`GRUB_GFXMODE=1920x1080x32,auto` (the panel's mode) and `splash` on the kernel command line for
[plymouth](plymouth.md). `setup.sh` runs `grub-mkconfig -o /boot/grub/grub.cfg` only when that
file or the theme package changed. Their sha256 is kept in `grub-cfg.stamp` (gitignored), and
grub-mkconfig checks the new file before it replaces the old one. A machine without
`/boot/grub/grub.cfg` boots with another loader and is skipped.
