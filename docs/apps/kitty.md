# kitty

The terminal (alt+return), the dropdown terminal (alt+esc) and the floating terminal (alt+shift+t), also every app's terminal: `xdg-terminals.list` names it for xdg-terminal-exec, which GLib uses to start `Terminal=true` apps (helix, vim).

The dropdown is a kitty window with the class `kitty-dropdown`, shown and hidden by mango's `toggle_named_scratchpad` (`mango/.config/mango/bind.conf`, rule in `rule.conf`). The first alt+esc starts it; after that alt+esc shows or hides the same shell, so history and running jobs survive. It floats against the top edge of whatever tag you view, 80% of the screen wide and half as tall, and alt+q closes it like any window. kitty's own quick-access kitten is not used: it is a layer surface mango never selects, so alt+q while it was open closed whichever window mango had selected instead, even one on another tag.

The floating terminal is a new kitty with the class `kitty-float` each time: `rule.conf` floats it at 800x600 in the middle of the screen. Use it for a one-off command next to a tiled layout; the dropdown is the shell that persists.

Copy and paste work like in GUI apps:

- **Ctrl+C** copies the selection and clears it; with nothing selected it is ^C (interrupt) as always, so the next Ctrl+C after a copy interrupts again (`copy_and_clear_or_interrupt`).
- **Ctrl+V** pastes the clipboard (bracketed paste: the shell inserts it without running it). Ctrl+Shift+C/V still work.
- A literal ^V (vim's block select, zsh's quoted-insert) is **Ctrl+Shift+Alt+V**.
- Selecting text fills the primary selection, so middle click pastes it anywhere.

Colors come from `colors.conf` (the palette's terminal colors; tabs, borders and the cursor trail from its roles). `theme set` recolors open windows at once: `reload.sh` sends SIGUSR1, which makes kitty re-read its config. Tabs (ctrl+shift+t) show as powerline segments at the top, like the bar, and only when there are two or more. fastfetch draws its logo with kitty's graphics protocol.
