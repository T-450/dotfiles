# imv

imv, the image viewer: just the image on the desktop color, in the palette's colors.

[imv](https://sr.ht/~exec64/imv/) opens images (`xdg-open`, Thunar, `imv FILE|DIR`) on `bg_desktop` with no frame, toolbar or status line. Images larger than the window shrink to fit; smaller ones keep their own size (`scaling_mode = shrink`). `d` shows a one-line strip at the bottom in the widget color: the file name, size, zoom and position in the folder. The colors come from `config.tmpl`; windows opened after `theme set` get the new ones.

imv keeps its own keys: `[`/`]` or the arrows step through the folder, `h j k l` pan, `i`/`o` zoom, `a` actual size, `r` reset, `Ctrl+r` rotates, `f` fullscreen, `t` starts a slideshow, `x` closes the image, `q` quits. Added: `y` copies the image to the clipboard, `Y` its path, and `W` makes it the wallpaper (`wallpaper-set`, see [swaybg](swaybg.md)).

`setup.sh` makes imv the default viewer for every image type its desktop file lists.
