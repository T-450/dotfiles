# way-displays

Display manager: each display gets its native resolution at its highest refresh and a scale from its pixel density, the laptop panel sits rightmost with bottom edges aligned, the LG UltraFine is pinned to scale 1.25, and the panel turns off while the lid is closed with an external display connected. A user daemon (`way-displays.service`) talks to mango over wlr output management and reads the lid with libinput; `mango-monitor` is the glue for mango's reloads and idle sleep. Design and reasoning: [Displays](../designs/displays.md).

## Changing things

`way-displays -g` prints every display with its mode, scale, position and why. `-s SCALE 'ULTRAFINE' 1.5` or `-s MODE ...` change the live state, `-t DISABLED eDP-1` toggles a display, `-w` saves the live state to `cfg.yaml`. `cfg.yaml` is linked into the repo, so `-w` writes through the link and drops the comments: review `git diff` before committing. Keys: `man 5 way-displays`.

The panel toggle (super+m p, `mango-monitor toggle`) is a way-displays override that ends when the lid state agrees with it; unplugging the last external display while it holds would leave no display on, so `mango-monitor sync` toggles it back then. `way-displays.service` runs `mango-monitor stop-hook` as `ExecStopPost`: it empties mango's generated rule file when the session ends, or when the lid rule no longer holds (a manual stop, the start limit: lid open, or no external display on), and keeps it only while the lid is closed over an enabled external display, so a restart (install.sh, a crash) does not light the panel behind a closed lid. If wlr-randr fails the file is left alone. At idle `mango-monitor sleep` pauses the daemon and holds a lid inhibitor while an external display is connected (see [Session](../session.md#idle)).

One-time step: set the LG's picture mode to sRGB in its on-screen menu. Its panel is wide gamut (near DCI-P3) and sRGB content looks oversaturated without it.

Not possible on this hardware and build: VRR (Intel Gen9 has no adaptive sync, so `VRR_OFF` for all), HDR and ICC profiles (need mango's Vulkan renderer; this build uses GLES), 10 bits per colour (only raised for HDR).
