# way-displays

Display manager: each display gets its native resolution at its highest refresh and a scale from its pixel density, the laptop panel sits rightmost with bottom edges aligned, the LG UltraFine is pinned to scale 1.25, and the panel turns off while the lid is closed with an external display connected. A user daemon (`way-displays.service`) talks to mango over wlr output management and reads the lid with libinput; `mango-monitor` is the glue for mango's reloads and idle sleep. Design and reasoning: [Displays](../designs/displays.md).

## Changing things

`way-displays -g` prints every display with its mode, scale, position and why. `-s SCALE 'LG' 1.5` or `-s MODE ...` change the live state, `-t DISABLED eDP-1` toggles a display, `-w` saves the live state to `cfg.yaml`. `cfg.yaml` is linked into the repo, so `-w` writes through the link and drops the comments: review `git diff` before committing. Keys: `man 5 way-displays`.

One-time step: set the LG's picture mode to sRGB in its on-screen menu. Its panel is wide gamut (near DCI-P3) and sRGB content looks oversaturated without it.

Not possible on this hardware and build: VRR (Intel Gen9 has no adaptive sync, so `VRR_OFF` for all), HDR and ICC profiles (need mango's Vulkan renderer; this build uses GLES), 10 bits per colour (only raised for HDR).
