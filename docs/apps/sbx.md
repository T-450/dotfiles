# sbx

Docker Sandboxes (`sbx`): runs a coding agent (Claude Code, Codex, OpenCode, ...) in its own microVM with your project mounted, so an agent running without approval prompts can't reach the rest of the machine.

Each sandbox is a KVM microVM with its own container engine inside, not a container on the host: the boundary is a VM, not a namespace. Podman ([podman](podman.md)) stays the engine for your own containers; sbx is for agents you don't want on your host.

- **Sign in once**: `sbx login` (a Docker account), then `sbx policy init allow-all|balanced|deny-all`, the global network policy for agents (Docker recommends `balanced`; `sbx policy allow network HOST:PORT` adds sites later). Both are runtime state in `~/.local/state/sandboxes`, never repo files.
- **Run an agent**: `sbx run --memory 4g claude` in a project folder (`sbx ls`, `sbx stop NAME`, `sbx rm NAME`). Always pass `--memory`: the default is half the machine's RAM (about 7.6 GB here), which leaves nothing beside runner-up's 6 GB CI VM. Run one sandbox at a time.
- **The daemon**: `sbx` starts `sandboxd` when a command needs it; nothing starts at login. `sbx daemon stop` ends it; `sbx diagnose` checks the install.
- **Networking** is user-mode (gVisor's network stack inside sbx): a sandbox reaches the network through sbx itself. Checked on this machine with a running sandbox: no host firewall rule changed (`nft list ruleset` identical apart from counters), no host network interface appeared, and nothing reached Podman although `DOCKER_HOST` pointed at it.

Packaging: Docker ships `.deb`, `.rpm` and a static tarball; `sbx/pkg/docker-sbx/PKGBUILD` installs the tarball, pinned by the release's SHA-256, under `/usr/lib/docker-sbx/` in the layout of its own installer (`bin/` and `libexec/`, which sbx finds at `../libexec` from its resolved path), with `/usr/bin/sbx` a link. sbx has no self-update; a new version is a pkgver and sha256 bump. It is proprietary software (Docker, Inc.).

Rollback: `sbx reset` (removes every sandbox and its state), `sbx daemon stop`, revert the commit, `sudo pacman -Rns docker-sbx`.
