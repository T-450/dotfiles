# gslapper

Video wallpapers for the desktop, when the current wallpaper is a video. hyprlock and the greeter use static images.

`gslapper.service` plays `~/.local/state/wallpaper/current` looped and filling every output, but
starts only when that link is a video (`ExecCondition=wallpaper-is video`); `swaybg.service` takes
an image the same way, so `wallpaper-set FILE` restarts both and one of them runs
([swaybg](swaybg.md)). gslapper decodes through GStreamer; `gst-plugin-va` gives it the VA-API
decoders, so the loops (10-bit HEVC) play on the GPU, and `-p` pauses playback while windows hide
the wallpaper. The link is the state, so gslapper keeps none of its own (`--no-save-state`).

The desktop uses gslapper rather than mpvpaper. hyprlock can't play video, so the lock screen
keeps an image of its own ([hyprlock](hyprlock.md)); the greeter's backdrop is a static image via
swaybg ([greeter](greeter.md)).
